# idv-auto-qte

自动处理第五人格中，修机、治疗时出现的校准事件（QTE快速反应事件）

## 如何使用

克隆代码库

```
git clone https://github.com/qwe5283/idv-auto-qte.git && cd idv-auto-qte
```

安装依赖

```
pip install -r requirements.txt
```

启动截图服务（需要以管理员权限运行）

```
python app.py
```

启动后就可以切到第五人格PC客户端或MuMu模拟器（推荐使用MuMu模拟器，因为客户端可能会扫盘），程序会开始截图并托管校准事件

---

你也可以传入自己的录屏文件查看识别效果

```
python app.py screenrecord.mp4
```

## 已知问题

脚本在MuMu模拟器下QTE击打时机不稳定，可能偏快或偏慢。初步猜测是游戏客户端在渲染画面时通过提交DXGI绘制画面导致MSS截图同步等待，脚本截图采样与游戏渲染绘制节奏被强制同步，保证了脚本运行在游戏客户端下的稳定性。但是MuMu模拟器中，宿主窗口的渲染循环独立于安卓VM，宿主窗口仍然以显示器刷新率向DWM提交绘制，这是脚本截图采样与游戏渲染绘制出现异步性的原因，产生严重的时间混叠问题，脚本无法精确预测QTE到达时间。

如果你有意向改进图色识别，预测算法，架构重构...欢迎提交PR
